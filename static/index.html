Resume match scoring

Paste your resume below and save it, then use "Score jobs vs resume" to grade every active posting A (excellent fit) through F (poor fit) against it. Saving a new resume clears existing grades so everything gets re-scored.

Re-parse with AI

New job postings are already parsed with the LLM automatically as they come in during refresh (clearance, salary, location, equity). Use this to re-check postings already in the database -- it re-derives every listed field from scratch and overwrites what's there now, which is the only way to fix a wrong value (a wrong field looks the same as a right one until it's re-checked). Structured salary data the ATS gave us directly is left alone. This can process a lot of jobs at once -- scope it down if you just want to fix what's currently on screen.
